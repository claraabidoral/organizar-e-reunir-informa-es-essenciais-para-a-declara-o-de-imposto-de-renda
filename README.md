# Organizador de Declaração de Imposto de Renda

Projeto desenvolvido para o desafio **Criando um Organizador de Declaração de Imposto de Renda**, com o objetivo de criar uma ferramenta em Excel para reunir e organizar informações importantes para a preparação da declaração.

## Objetivo

A ferramenta foi desenvolvida para facilitar a organização das informações e documentos necessários para a Declaração de Imposto de Renda.

A planilha permite centralizar dados do titular, informes de rendimentos, pagamentos, despesas e outras movimentações importantes.

## Estrutura da Planilha

A ferramenta foi organizada nas seguintes abas:

###  MENU

Tela inicial da ferramenta, apresentando as principais etapas de preenchimento e permitindo acompanhar a organização das informações.

###  TITULAR

Área destinada ao cadastro das informações do contribuinte, como:

- Nome completo;
- CPF;
- Data de nascimento;
- Endereço;
- Telefone;
- E-mail;
- Informações bancárias.

### INFORMES

Área utilizada para registrar os informes de rendimentos recebidos de empregadores, bancos e outras instituições.

A planilha permite registrar:

- Instituição ou fonte pagadora;
- CPF ou CNPJ;
- Tipo de rendimento;
- Rendimentos tributáveis;
- Imposto de Renda retido;
- Rendimentos isentos ou não tributáveis.

Também são apresentados totais automáticos dos valores registrados.

### NOTAS

Área destinada à organização de pagamentos, despesas e outras movimentações.

É possível registrar:

- Data;
- Categoria;
- Descrição;
- CPF ou CNPJ;
- Valor;
- Indicação de possível dedutibilidade;
- Existência de comprovante;
- Observações.

### APOIO

Foi criado um checklist para auxiliar na organização dos documentos necessários para a declaração.

O usuário pode acompanhar se cada documento está:

- Pendente;
- Separado;
- Conferido.

##  Recursos utilizados

Durante o desenvolvimento foram utilizados diferentes recursos do Excel, como:

- Fórmulas e funções;
- SOMA e SOMASE;
- Validação de dados;
- Listas suspensas;
- Formatação personalizada;
- Formatação condicional;
- Organização em diferentes abas;
- Resumos automáticos;
- Campos de entrada destacados.

## Melhorias realizadas

Além das funcionalidades propostas no desafio, a ferramenta possui um checklist de documentos e áreas de resumo para facilitar a visualização das informações registradas.

##  Observação

Este projeto possui finalidade educacional e de organização das informações.

Por se tratar de um repositório público, não foram utilizados dados pessoais, bancários ou fiscais reais.

A ferramenta não substitui os sistemas e canais oficiais utilizados para realizar a Declaração de Imposto de Renda.
